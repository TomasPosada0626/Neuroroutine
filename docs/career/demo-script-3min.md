# 3-Minute Demo Script

## 0:00 - 0:30 Product framing

- Problem: routine execution consistency, not just task listing.
- Differentiation: behavior-first flow + offline continuity + security-by-default.

## 0:30 - 1:20 Happy path

1. Login
2. Create routine
3. Add tasks
4. Complete one task
5. Show dashboard progress updates

## 1:20 - 2:10 Resilience

1. Explain offline queue behavior
2. Show sync status and retry controls
3. Mention RLS isolation and optional multi-user E2E scenario

## 2:10 - 3:00 Engineering maturity

1. Show CI gates and release workflow
2. Show ADRs/C4 and security docs
3. Show current metrics and roadmap milestone focus
