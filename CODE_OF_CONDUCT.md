# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contribute to a positive environment:

- Being respectful and constructive.
- Giving and receiving feedback professionally.
- Focusing on what is best for the project and community.

Examples of unacceptable behavior:

- Harassment, insults, or discrimination.
- Public or private attacks against contributors.
- Publishing private information without explicit permission.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of conduct and may remove, edit, or reject contributions that violate these standards.

## Reporting

If you experience or witness unacceptable behavior, open a private report via repository maintainers.
